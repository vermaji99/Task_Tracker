# Handwritten Submission — Instructions for Candidate

You must hand-write the content in `content-to-write.md` onto four separate sheets of paper, then photograph or scan each sheet and drop the image files into this `handwritten/` folder.

## Required pages

- **Page 1** → Application overview & my debugging approach
- **Page 2** → Highest-value bug #1 (SQL operator precedence / archived tasks leaking)
- **Page 3** → Highest-value bug #2 (Thread.sleep latency injection + invalid status 500)
- **Page 4** → Testing, other improvements, and key lessons

## Writing and scanning tips

- Use a plain white A4 sheet and a dark-ink pen (blue or black).
- Keep your writing legible; you will be asked to walk through these pages in the follow-up call.
- Write page numbers in the corner of each sheet so the reviewer can cross-reference.
- Photograph in good light with no shadows, or use a scanner app that crops and deskews automatically.
- Do not include `content-to-write.md` or this README as "handwritten" work — the employer wants your own handwriting, not printed markdown.

## Final sanity check before pushing

- 4 JPG/PNG files present inside `handwritten/`.
- Every image is readable at 100 % zoom.
- Both `handwritten/README.md` and `handwritten/content-to-write.md` are also present in the repo.
